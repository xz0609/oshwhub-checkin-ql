# 立创开源硬件平台自动签到 - 青龙版

基于 Python 的立创开源硬件平台（[oshwhub.com](https://oshwhub.com)）每日签到脚本，适配青龙面板。采用 **Cookie 方式**（手动抓取登录态 Cookie），每日自动签到获取积分，并展示当前总积分与本月连续签到天数。

单文件、零第三方依赖（仅使用 Python 标准库），无需额外安装 `requests` 等库，可直接通过青龙面板订阅或上传部署。

> 说明：立创/嘉立创登录中心已升级为国密 SM2 加密 + 滑块验证码，纯密码登录难以自动化，故本脚本改用 Cookie 方式，稳定且无验证码烦恼。

## 功能

- Cookie 方式签到，无需密码、无需处理验证码
- 每日自动签到，获取积分
- 展示签到结果、本次获得积分、当前总积分、本周签到天数、本月连续签到天数
- 支持多账号并发签到（每个账号独立线程）
- 每个账号签到前支持随机延迟，错峰分散请求、降低风控
- Cookie 自动脱敏，日志与通知不泄露登录凭证
- 网络异常自动重试三次，Cookie 失效自动识别
- 支持青龙内置通知（企业微信、Telegram、PushPlus 等）

## 环境要求

- 青龙面板 2.x 或更高版本
- Python 3.7 或更高版本
- **无需安装任何第三方 Python 依赖**（仅使用标准库）

## 获取 Cookie

1. 用浏览器登录 [立创开源硬件平台](https://oshwhub.com)。
2. 按 `F12` 打开开发者工具，切换到 `Network`（网络）面板。
3. 刷新签到页 <https://oshwhub.com/sign_in>。
4. 在请求列表中找到 `getSignInProfile` 请求。
5. 点击该请求，在 `Headers` 中找到 `Request Headers` 下的 `Cookie`。
6. 复制 `Cookie` 后面的**完整值**（形如 `jlc_vid=xxx; oshwhub_session=xxx; ...`）。

只需要 Cookie 的值，不要复制 `Cookie:` 这个名称。Cookie 属于敏感凭证，不要提交到 GitHub、截图公开或发送给他人。主动退出账号后 Cookie 会失效。

> 多账号：分别登录各账号并抓取 Cookie，每个 Cookie 独立一行。

## 青龙部署

### 1. 订阅仓库/上传脚本

- **方法一、📌 订阅仓库（推荐）**：在青龙面板「订阅管理」中新建订阅，类型选 `公开仓库`，粘贴下方订阅地址，保存并运行后，脚本自动出现在「脚本管理」中。

  订阅地址： `https://wget.la/https://github.com/xz0609/oshwhub-checkin-ql.git`

- **方法二、上传脚本**：将 `oshwhub-checkin-ql.py` 上传到青龙面板「脚本管理」。

### 2. 配置环境变量

在「环境变量」中新建：

```text
名称：OSHW_COOKIE
值：jlc_vid=xxx; oshwhub_session=xxx; ...
```

单账号直接填写一个 Cookie。多账号使用换行符分隔，每行一个 Cookie，不加引号、不添加空行。

可选环境变量（不配置时使用默认值）：

| 变量名                | 默认值    | 说明                                                     |
| ------------------ | ------ | ------------------------------------------------------ |
| `OSHW_COOKIE`      | 无（必填）  | 登录态 Cookie，多账号换行分隔                                     |
| `PRIVACY_MODE`     | `true` | 隐私模式，日志与通知中对 Cookie 脱敏                                 |
| `RANDOM_SIGNIN`    | `true` | 是否启用签到前随机延迟，设为 `false` 关闭延迟并立即签到                       |
| `MAX_RANDOM_DELAY` | `1800` | 每个账号签到前最大随机延迟秒数（仅 `RANDOM_SIGNIN=true` 时生效，置 `0` 即不延迟） |
| `X_FORWARDED_FOR`  | 空      | 可选，伪装来源 IP                                             |

### 3. 配置通知

在青龙「系统设置 -> 通知设置」中启用需要的通知渠道，例如企业微信机器人。本脚本不需要额外的通知环境变量。

### 4. 创建定时任务

在「定时任务」中新建：

```text
名称：立创开源硬件平台自动签到
命令：task oshwhub-checkin-ql.py
定时规则：10 8 * * *
```

建议每天运行一次。重复运行会显示「今日已签到」。签到时间建议设置在白天（如早上 8 点后），凌晨 0 点集中签到更容易触发风控。

手动运行定时任务，正常日志类似：

## 常见问题

### 提示未找到 OSHW_COOKIE 环境变量

确认环境变量名称严格为 `OSHW_COOKIE`，并且变量已启用。

### 提示 Cookie 已失效（未登录或已过期）

- Cookie 已过期或主动退出登录导致失效，请重新登录并抓取新的 Cookie。
- 确认复制的是完整 Cookie，不要遗漏分号或键值对。

### 提示被 WAF 拦截，Cookie 可能不完整

复制的 Cookie 不完整。请确保复制 `Request Headers` 中 `Cookie` 的**完整值**，包含所有键值对。

### 提示网络错误 / 请求连续失败

- 检查青龙容器网络是否正常，能否访问 `oshwhub.com`；
- 脚本已内置三次重试，可尝试再次手动运行。

### 签到成功但任务显示失败

脚本会在任一账号失败或通知调用失败时返回退出码 `1`。查看日志中的失败账号或通知错误。

### 无法加载青龙内置通知模块

确认青龙脚本目录中存在 `notify.py`，并检查青龙通知设置是否已启用。
